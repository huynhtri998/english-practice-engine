# Evaluate Answer Prompt

Evaluate one learner answer against the intended Knowledge Unit and practice item.

## Response order

1. State whether the answer is correct and natural.
2. If incorrect, give the corrected sentence.
3. Explain the smallest useful rule or contrast.
4. Assign one error category when useful.
5. Decide whether an in-session retest is needed.

## Keep feedback concise

During rapid drills, do not turn one mistake into a long grammar lesson.

Use source-grounded KU content for the tested distinction. General English knowledge may help judge naturalness, but do not silently replace the source concept.

## Outcome labels

Use one of:

- `strong`
- `correct-with-hesitation`
- `self-corrected`
- `incorrect`
- `repeated-error`

## Dimension rules

Update only the dimension that the item actually tests:

- recognition item → recognition
- controlled production / Vietnamese → English / mixed production → production
- speaking-reflex item → speaking

Do not infer speaking mastery from a written recognition answer.

## Retest rule

Queue a retest when:

- the answer is incorrect on the target distinction
- the same category has appeared earlier in the session
- the learner recognized the rule but failed to produce it
- speaking output shows a recurring hesitation or form-selection problem

The retest must use a different sentence or context.

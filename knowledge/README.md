# Knowledge

Canonical knowledge lives here and is organized by concept, not by source book.

A Knowledge Unit should be independently reviewable and reusable by practice generators.

Recommended naming:

```text
knowledge/grammar/present/present-simple.md
knowledge/grammar/present/present-continuous.md
knowledge/grammar/present/present-simple-vs-continuous.md
```

Use front matter or structured sections that can later be migrated to YAML/JSON without losing meaning.
